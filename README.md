# 🌟 Roja Firmanda — Portfolio Website

Selamat datang di repositori portfolio pribadi **Roja Firmanda** — seorang **Software Engineer**, **Web Developer**, dan **IT Support** profesional asal Kendal, Jawa Tengah, Indonesia.

Website ini dibuat dengan pengalaman 3D immersive bertema **Neon Cyberpunk**, menggabungkan visual Three.js interaktif dengan scroll-based storytelling yang menampilkan perjalanan karier, keterampilan, proyek, dan kontak.

🌐 **[Lihat Langsung →](https://roja28.github.io/PortfolioRoja)**

---

## ✨ Fitur

- **🎮 3D Immersive Experience** — Lingkungan Three.js dengan grid lantai, partikel neon, kubus wireframe, portal, dan efek bloom
- **📜 Scroll-Based Navigation** — Setiap section (Hero, About, Skills, Experience, Projects, Contact) muncul saat di-scroll dengan transisi kamera 3D
- **📱 Responsif** — Tampilan optimal di desktop, tablet (termasuk iPad Pro 11"), dan smartphone
- **🌙 Dark Theme** — Tema gelap dengan aksen neon magenta, cyan, dan kuning
- **🦋 Navigasi Lengkap** — Navbar dengan link Home, About, Skills, Experience, Projects, Contact, dan hamburger menu untuk mobile
- **📄 Download CV** — Tersedia dalam Bahasa Indonesia dan Inggris
- **📬 Form Kontak** — Formulir untuk mengirim pesan langsung
- **⚡ Animasi Halus** — Efek transisi, pulse, float, dan scroll yang mulus dengan GSAP + ScrollTrigger

## 🛠️ Teknologi

### Frontend
- **HTML5** — Struktur halaman
- **CSS3** — Styling dengan custom properties, responsive design
- **JavaScript (ES Modules)** — Interaktivitas dan logika halaman

### 3D & Animasi
- **[Three.js](https://threejs.org/)** (v0.160.0) — Rendering 3D dengan post-processing (Bloom, Vignette)
- **[GSAP](https://gsap.com/)** (v3.12.5) — Animasi scroll dan timeline
- **ScrollTrigger** — Plugin GSAP untuk scroll-based animation

### Library & Tools
- **Google Fonts** — Syne, DM Mono, Space Grotesk
- **EffectComposer** — Bloom effect, shader pass

## 🚀 Cara Menjalankan

1. **Clone repositori ini**
   ```bash
   git clone https://github.com/roja28/portfolio.git
   cd portfolio
   ```

2. **Buka file `index.html`**
   - Klik kanan → Open with Live Server (VS Code)
   - Atau buka langsung di browser

3. **Jelajahi** — Scroll untuk berpindah antar section, nikmati efek 3D neon cyberpunk

> **Catatan:** Pastikan koneksi internet aktif karena Three.js dan GSAP di-load dari CDN.
